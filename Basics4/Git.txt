Step-by-Step InstructionsCreate a new repository on GitHub by clicking the New button or the + icon in the top right corner.
Type a name for your repository, choose if it is public or private, and leave the "Add a README file" box unchecked if you already have files on your computer. Click Create repository.
Open your computer terminal or command prompt and navigate to your project folder using the cd command.
Type git init to turn your project folder into a Git repository.
Type git add . to select all the files in your folder.
Type git commit -m "Initial commit" to save your files locally with a message.
Copy the remote URL provided on your new GitHub repository page (it looks like https://github.com).
Type git remote add origin YOUR_URL_HERE in your terminal to connect your computer to GitHub.
Type git branch -M main(or master) to set your main branch name.
Type git push -u origin main to upload your files to GitHub

You can update a newly added file or folder by staging it with git add, committing it with git commit, and pushing it with git push.

Open your computer terminal and go to your project folder using the cd command.
Type git status to see a list of your newly added or changed files and folders.
Type git add . to select all new files and folders, or type git add folder_name/file_name to add only a specific item. )(or)
Type git add -f path/to/your/file.txt

Type git commit -m "Add new file or folder" to save the changes to your local history with a short note.
Type git push to upload your updates to GitHub.

# 1. Switch to the main branch
git checkout main

# 2. Pull the latest online changes to be safe
git pull origin main

# 3. Merge your new files from master into main
git merge master

# 4. Push the combined updates back to GitHub
git push origin main
